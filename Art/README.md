# Art

Source material. Nothing in here ships, the game only ever reads `Assets`.

- `characters/` the sheets and `definition.hor` files the characters were cut from before they were .ase files, and
  the_man's first Aseprite file. `tools/build_ase.py` turns a sheet into the .ase that goes in `Assets/sprites/characters`.
- `backgrounds/`, `ui/`, `screens/` art that was drawn and then not used (the old menu sheet, the first logo, a loading
  screen). Kept in case it comes back, out of the way until then.
- `fonts/` two bitmap fonts nothing reads any more, the UI uses the engine's.
- `tools/` the scripts that make the .ase files, see the top of each one for how.

Old builds don't live in the repository any more, they were a couple of hundred megabytes of exes nobody diffs. The
releases page is for those.
